# Bilou — Portfolio Danseur Pro Breaking

Site vitrine de Romain "Bilou" Marquilly, danseur de breakdance professionnel,
performer et acrobate.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Le site est déployé automatiquement sur GitHub Pages via GitHub Actions à
chaque modification du dossier `bilou-portfolio/`.
